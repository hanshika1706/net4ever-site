# Net4Ever Billing Dashboard 🌐⚡

A real-time, cloud-synced broadband management web application built to streamline customer renewals and payment tracking.

## 🚀 Features
- **Cloud Sync:** Uses Firebase Firestore for real-time data synchronization across multiple devices (Mobile & Laptop).
- **Excel Integration:** Allows bulk importing of customer data from `.xls` / `.xlsx` files.
- **Smart Due Alerts:** Automatically moves customers to a "Due for Recharge" section based on their expiry date.
- **One-Tap Renewal:** Simplifies the billing process for field work.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Database:** Firebase Firestore (NoSQL)
- **Deployment:** GitHub Pages
- **Tools:** SheetJS for Excel parsing
